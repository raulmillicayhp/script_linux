# Ubuntu Scripts

Repositorio donde comparto scripts desarrollados para Ubuntu, enfocados en automatizar tareas de administración, configuración, mantenimiento y despliegue de servicios.

El objetivo de este proyecto es centralizar herramientas que utilizo en entornos reales, priorizando la simplicidad, la seguridad y las buenas prácticas de scripting en Bash.

## Contenido

En este repositorio podrás encontrar scripts para tareas como:

- Administración de sistemas.
- Configuración inicial de servidores.
- Automatización de tareas repetitivas.
- Instalación y configuración de servicios.
- Hardening y ajustes de seguridad.
- Monitoreo y mantenimiento.
- Gestión de actualizaciones.
- Herramientas de soporte y diagnóstico.

## Requisitos

- Ubuntu
- Bash
- Permisos de administrador (`sudo`) para los scripts que lo requieran.

## Objetivo del repositorio

Este repositorio está pensado como una colección de herramientas prácticas para administradores de sistemas, profesionales de infraestructura, estudiantes y cualquier persona que necesite automatizar tareas en Ubuntu.

Los scripts se irán incorporando y mejorando de forma continua a medida que sean utilizados y probados en diferentes escenarios.
